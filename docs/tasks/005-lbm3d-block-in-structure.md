# 任务 005：时间步局部块放回真实结构里

设计文档：`docs/design/lbm3d-cl.md`，先读"第三轮定稿"第 8、9 条。基线是当前 HEAD（任务 004 `0dc0bb6` + 任务 003 `958e84c`）。

## 为什么改

任务 004 按设计说明做了一个独立的 5×5×5 教学格点（`src/ui/teaching-lattice.js`），有自己的求解器和人工结构。**这是设计负责人理解错了用户的要求**，不是你实现错了。用户要的是：局部块就是真实重构结构里的一块，放在它原来的位置上，周围的真实结构看得见。

## 目标

时间步模式下：

1. 画面里始终显示真实的 64×32×32 结构，用剖切显示，切面穿过局部块。
2. 5×5×5 局部块嵌在原位，块内格点画 7 个分量方块，逐子步演示。
3. 上下共用一个求解器（即下面浓度面板的那个）。
4. 不出现浓度色图。

保留任务 004 的：下面自动求解 + 时间轴、剖切框默认值修正、4 个可见子步芯片、子步说明文案、检查器的 Σf 显示。

## 允许改动的文件

- 修改：`lbm3d-cl/index.html`、`style.css`、`src/app.js`、`src/ui/*.js`
- 删除：`src/ui/teaching-lattice.js`

**不改**：`src/engine/`、`test/`、`tools/`、`vendor/`、`reference/`、`docs/`、`.claude/`。

## 风格约束

同任务 004。

## 一、求解器

- 删掉教学格点的独立求解器。时间步模式、局部块、检查器、下面浓度面板全部用同一个求解器（任务 004 里下面那个）。
- 进入时间步模式时暂停下面的自动求解；时间轴上方显示一行小字"时间步演示中，自动求解已暂停"和按钮「继续自动求解」。点它或切回构建模式即恢复。
- 时间步演示推进的步数照样计入求解器的 t；每到 t 是 25 的倍数、且刚完成一个完整时间步时，照常存一帧。
- 时间轴拖到较早的帧时，只有下面的体渲染、切片、曲线、诊断跟着变；上面的局部块和检查器始终显示求解器当前状态，并在说明文字末尾的小字行里写"局部块为当前第 n 步"。

## 二、真实结构的剖切背景

- 时间步模式下，上面画布显示与构建模式完成态（stage 6）相同的结构：碳、铂、离聚物实心方块（相位色，不透明度 1），缓冲层与墙半透明板。孔隙格点的点不画。
- 剖切：用构建模式的局部裁剪平面机制，把 y < y0 的部分裁掉（y0 为局部块的 y 起点），x、z 不裁。切面正好露出局部块的前表面。剖切面板在时间步模式下隐藏。
- **局部块内部**的固相格点：不透明度 0.25、`depthWrite: false`，让块内的分量方块看得见；块外的固相保持不透明。
- 局部块外框：金色线框（`#c99a2e`，边长 5.04，线宽按 three.js 默认）。

## 三、局部块

- 位置：`x0 = clamp(selX − 2, 3, L − 8)`、`y0 = clamp(selY − 2, 0, H − 5)`、`z0 = clamp(selZ − 2, 0, W − 5)`。不跨 y、z 周期边界，也不进缓冲层和墙。
- 块内流体格点画 7 个分量方块，块外不画。
- 分量方块：**固定颜色 `#1f7a72`**，不按浓度着色。尺寸和不透明度按块内归一化：设 `f_ref = max(块内所有流体格点所有分量)`（取子步前的值，块内全为 0 时取 1），边长 `0.10 + 0.22·√min(1, f_k / f_ref)`，不透明度 `0.35 + 0.65·√min(1, f_k / f_ref)`。
- 宏观量子步的中心球：灰色 `#8e9a96`，半径 `0.12 + 0.25·∛min(1, Σf / Σf_max)`（Σf_max 为块内最大值），选中格点旁标 `Σf = 0.xxxx`。
- 迁移、反弹、碰撞的动画、时长、缓动沿用任务 002/004。入口、反应两个子步不播放动画，执行时直接跳过（与任务 004 相同）。
- 默认选中格点：在 x ∈ [6, 12] 内找一个孔隙格点，满足 +x 或 −x 邻居是碳或铂、另有至少 3 个孔隙邻居，按 x、y、z 升序取第一个。找不到时取 (8, H/2, W/2)。
- 点击：在块内点格点即选中，检查器切换；块随之移动（按上面的 clamp 规则）。点块外的结构不响应。

## 四、镜头

- 进入时间步模式或局部块移动时，镜头用 600 ms（easeInOutCubic）对准块中心，方向 `(0.32, −1, 0.5)`，距离使块占画布高度约 45%，能同时看到块和周围结构。
- 之后用户用滚轮、拖动自由调整；块移动时才重新对准。
- 删除「全局 / 局部」按钮。URL 的 `cam` 参数删除。
- 「重置视角」在时间步模式下回到上述对准块的视角。

## 五、删除教学格点

- 删除 `src/ui/teaching-lattice.js` 及所有引用、「重置教学格点」按钮、说明文字末尾关于教学格点 Δt/τ 的小字。
- 说明文字末尾小字行改为："局部块 (x0..x0+4, y0..y0+4, z0..z0+4) · 当前第 n 步"。

## 六、固定状态 URL

| 参数 | 含义 |
|---|---|
| `t`、`sub`、`ap` | 作用于共用求解器：先跑 t 个完整时间步，再执行到可见子步 `sub`（0~3），冻结在 `ap` |
| `sel` | 选中格点 `x,y,z`，决定局部块位置 |
| `frame` | 只在不带 `t` 时生效：自动求解到第 frame 帧后停止 |
| 其余 | 同任务 004 |

## 验收

我会在 1600×960 视口下打开以下 URL 截图。你完成后自己逐个打开，确认控制台无报错，在汇报中列出：

1. `?mode=step&t=300&sub=0&ap=0.5`：迁移中间帧。局部块嵌在剖切后的真实结构里，块外结构不透明、看得清。
2. `?mode=step&t=300&sub=1&ap=0.5`：反弹中间帧。
3. `?mode=step&t=300&sub=2&ap=0.4`：宏观量，灰色球和 Σf。
4. `?mode=step&t=300&sub=3&ap=0.5`：碰撞中间帧。
5. `?mode=step&t=300&sub=0&ap=0.5&sel=20,10,10`：换一个位置，块和镜头跟着移动。
6. `?mode=build&stage=6`：构建模式不受影响。
7. `?frame=40`：下面时间轴与体渲染。

上次你的环境打不开浏览器，这次同样只需确认每个 URL 能打开、控制台无报错，截图由我来做。
