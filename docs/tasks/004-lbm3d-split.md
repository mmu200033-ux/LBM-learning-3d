# 任务 004：上下分开——5×5×5 教学格点 + 浓度扩散时间轴

设计文档：`docs/design/lbm3d-cl.md`，先读"第二轮定稿"三条。基线是任务 002 的提交（`c04ecd9`）。

## 目标

现在上下两块共用一个求解器：上面的局部块从真实结构里取，离入口远时分量几乎为 0；方块和中心球按浓度着色；下面只有点「连续求解」才动。改成：

- **上面「时间步」模式**：一个独立的 5×5×5 教学格点，有自己的求解器，只演示孔隙内的迁移、碰撞和固相反弹。不出现任何浓度色图。
- **下面浓度面板**：用真实重构结构单独求解，打开页面就自动算，按间隔存帧，配时间轴可暂停、拖动、重放。
- 「构建」模式保持不变，只修剖切框默认值（见第四节）。

## 一、教学格点（上面「时间步」模式）

### 结构

- 用 `createSolver` 建一个独立求解器，结构自己拼：`L = 7, H = 5, W = 5`，`dx = 5e-9`。
- x = 0 和 x = 6 两层为墙（`PHASE.WALL`），不显示；可见区域是 x = 1..5 的 5×5×5。y、z 周期（引擎默认）。
- 可见区域内放一块碳：可见坐标 x = 4..5、y = 1..2、z = 1..2（即全局 x = 4..5）设为 `PHASE.CARBON`，其余为 `PHASE.PORE`。`poreSize` 全部填 6。
- 参数：`i0: 0, eta: 0, cIn: 0`（无反应、无入口）。Δt 取让孔隙 τ = 1.0 的值：先用默认参数建一次求解器读出孔隙格点的 `D`，再用 `dt = 0.125 · dx² / D` 重建。实测 τ 写进汇报。
- 默认选中格点：可见坐标 (3, 1, 1)，它的 +x 邻居是碳，能同时看到迁移和反弹。

### 初值

- `reset()` 后直接写 `solver.f`：孔隙格点 i 的分量 k 为 `WEIGHT[k] · c_i · (1 + 0.4·r)`，`c_i = 1.0 − 0.12·(x_i − 1)`（左高右低，看得出净迁移），r 为种子 7 的 mulberry32 在 [−1, 1] 上的随机数。碳和墙格点的分量为 0。
- 写完后把 `solver.c` 设为各格点 7 个分量之和，供显示用。
- 方块尺寸归一化用参考值 `c_ref = 1.0`（取代原来的 `cIn`）：边长 `0.10 + 0.22·√min(1.5, f_k / (WEIGHT[k]·c_ref))`，不透明度 `0.35 + 0.65·√min(1, f_k / (WEIGHT[k]·c_ref))`。
- 页面加一个按钮「重置教学格点」，回到上述初值、t = 0。

### 子步

- 子步芯片只留 4 个：迁移、反弹、宏观量、碰撞。引擎仍按 6 个子步执行；入口、反应两个子步在教学格点里没有作用，执行时不播放动画、不停顿，直接跳过（`stepSub()` 连调）。
- 动画沿用任务 002 的迁移、反弹、碰撞，时长、缓动不变。
- 宏观量：7 个方块向中心收拢、中心出现球（半径公式不变，`c` 用 c_ref 归一化）。**球统一用灰色 `#8e9a96`，不用 viridis**。选中格点的球旁边显示 `Σf = 0.xxxx`（字号 11px，等宽字体）。
- 删除全局背景：时间步模式下上面画布里只画教学格点，不画重构结构、缓冲层板、剖切框。「全局 / 局部」切换按钮在时间步模式下隐藏。
- 镜头：进入时间步模式时对准 5×5×5 中心，块占画布高度约 75%，方向同全局默认 `(0.32, −1, 0.5)`。
- 教学格点内点击任意格点即选中，检查器跟着切换。

### 检查器（右上）

- 时间步模式下显示教学格点的选中格点：前 / 后 / Δ 表沿用任务 002。
- 宏观行把"浓度"改为 `Σf`，单位一栏留空；"源项"一栏去掉。
- 子步行写"子步：迁移 · 教学格点第 n 步"。

### 说明文字（定稿文案，替换任务 002 的四条）

- 迁移："每个格点的 6 个运动分量沿各自方向移到相邻格点，静止分量 f₀ 不动（式 2-32 左侧）。朝向碳的分量停在界面上，下一子步反弹。"
- 反弹："停在碳表面的分量原路返回，变成反方向的分量：f₁ 撞上去，就变回 f₂。碳格点里没有分布函数。"
- 宏观量："每个格点 7 个分量求和得到 Σf，就是这个格点的氧气浓度（式 2-38）。迁移和反弹只搬运分量，不改变全场总和。"
- 碰撞："每个格点在矩空间向平衡态 fᵢᵉᑫ = wᵢ·Σf 松弛（式 2-32 右侧、2-35、2-36）。Σf 不变，各分量之间的差别变小。"

## 二、浓度面板（下面）

### 求解

- 用 `reconstruct({ seed })` 的结构建第二个求解器，参数用引擎默认值，URL `dt=` 可覆盖（只作用于这个求解器）。
- 页面加载完自动开始算。每个动画帧在 14 ms 预算内推进完整时间步。
- 每 25 步存一帧，最多 200 帧（5000 步），存满后停止求解，时间轴显示"已到记录上限"。
- 每帧存：步数、物理时间、浓度场 `Uint8Array(N)`（`round(255·min(1, c/c_in))`，与体渲染纹理同格式）、`profileX()` 结果、`diagnostics()` 结果。

### 时间轴

- 放在浓度面板标题栏下方（或体渲染画布底部，二选一，写进推断清单），一行：播放/暂停按钮、滑块（0..已存帧数−1）、文字"第 n 步 · t = x.xx ns"、播放速度（0.5× / 1× / 2×）。
- 播放：以每秒 10 帧（×速度）依次显示已存帧，到最新一帧后停在最新帧并跟随新帧。
- 拖动滑块时暂停播放，体渲染、切片、剖面曲线、诊断数据都显示该帧。求解在后台继续，只追加帧不跳画面。
- 删除原来的「连续求解」按钮。「显示固相」「切片」控件保留。

## 三、上下解耦

- 上面教学格点和下面浓度求解器互不调用对方的数据。
- 「构建」模式下选中格点时，下面体渲染里的金色选中框照旧跟随；「时间步」模式下体渲染不画选中框（教学格点不在真实结构里）。
- 页脚的 Δt、η 显示下面浓度求解器的实际值；教学格点的 Δt 和 τ 显示在上面说明文字末尾一行小字里。
