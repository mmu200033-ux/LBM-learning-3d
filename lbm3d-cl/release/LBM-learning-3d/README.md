# LBM 三维学习演示（单文件版）

## 运行

只需双击 `LBM-learning-3d.exe`，不需要 Node.js，也不需要同目录下的其他文件。

程序会把内置的网页和 400 帧浓度缓存解压到系统临时目录，在本机随机端口启动静态服务器，并自动打开浏览器。关闭控制台窗口即可停止服务。

## 说明

- 默认 `seed=42` 已包含 400 帧真实 LBM 浓度缓存，可立即拖动完整时间轴。
- 更改 seed 后，如果没有对应缓存，页面会回退到浏览器实时计算。
- 同目录下的 `index.html`、`style.css`、`src/`、`vendor/`、`cache/` 仅用于网页版部署，单文件 exe 运行时不读取它们。
