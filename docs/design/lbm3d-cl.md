# 设计文档：催化层三维 LBM 演示（lbm3d-cl）

## 目标

做一个本地网页，用李兴博士论文第 2 章的模型，一步步展示三维 LBM 是怎么算出催化层内氧气浓度场的。读者是正在学 LBM 的研究生：看完要能说清楚"格点从哪来、分布函数每一步怎么变、浓度梯度为什么长这样"。

参照项目：[LBM-Learning](https://github.com/mmu200033-ux/LBM-Learning)（二维 D2Q9 教学页，按"开始 → 迁移 → 碰撞 → 反弹"分阶段演示，每个格点的分量都画成小方块，深浅表示数值）。本项目把同样的教学方式搬到三维、D3Q7、反应扩散。

## 已定稿的决定（2026-11-01 与用户确认）

1. **周期边界**：碳球、铂、离聚物的重构全部按 y、z 周期处理，与求解器一致。碳球跨出 y/z 边界的部分从对面接上。原代码 `carbon.c` 不周期、`pt.c`/`ionomer.c` 周期，导致底面出现"没有碳依附的铂"，本项目不沿用这一不一致。x 方向不周期。
2. **构建阶段显示全部格点**：65536 个格点都画，配一个可拖动的剖切框看内部。不再只画外表面。
3. **时间步模式用 5×5×5 局部块**：镜头飞进选中格点周围的局部块，块内每个格点的 7 个分量都画成方块，每个子步有对应动画（逐格点的向量运算，参照二维项目）。全域结构淡出作为背景。
4. **浓度用体渲染**：光线步进穿过三维浓度场，高浓度亮、低浓度透明，固相半透明灰。可选叠一张可拖动切片读数值。

## 页面布局（单页，三区）

- **左上（主区，约 60% 宽、上半屏 57%）**：三维格点。「构建」/「时间步」两种模式。
- **右上（检查器，约 40% 宽）**：选中格点的 D3Q7 七方向分布函数。
- **下方（全宽，下半屏 43%）**：左侧三维浓度体渲染，右侧沿 x 的平均浓度曲线、诊断数据、色标条。

界面细节与动画参数见任务 002（`docs/tasks/002-lbm3d-ui.md`）。

## 物理模型（本期范围）

只算氧气，过电势取定值 η（不解质子、电子电势）。其余与 `mass_transfer.cu` 一致：

- 孔隙：D_p = (1/D_b + 1/D_kn)⁻¹，D_kn 按局部孔径算。
- 离聚物：D_ion = 1.14698×10⁻¹⁰ λ^0.708，λ 由 RH 算。
- 缓冲层：虚拟扩散系数 D0 = 5×10⁻⁵ m²/s。
- 碳、铂、墙：反弹。
- 孔/离聚物界面：共轭边界（kis、H/RT = 1.5）。
- 反应：离聚物格点每有一个相邻铂格点，加一份 i0/(c_ref Δx) · c · (e^{kη} − e^{−kη})，k = 4·0.5·F/(RT)，c ≤ 0 时不反应。

与论文相比的简化：过电势定值、网格缩小、重构全周期。这三点要在页面上写明。

## 待确认

1. **克努森扩散的摩尔质量单位**。`mass_transfer.cu:356` 用 M = 32 代入 SI 公式，若按 kg/mol 应为 0.032，D_kn 相差约 31.6 倍。默认跟代码（32），任务 001 两种都算出来，由用户确认。
2. **`mass_transfer.cu:300-304`** 用 `cudaMemcpy(dst, 0, ...)` 清零，源指针为空，这几个 GPU 数组实际未初始化，可能需要改为 `cudaMemset`。不影响本演示，已告知用户。
