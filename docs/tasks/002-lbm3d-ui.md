# 任务 002：界面改版（全格点剖切、5×5×5 逐子步动画、体渲染浓度）

设计文档：`docs/design/lbm3d-cl.md`，先读"已定稿的决定"。依赖任务 001 的引擎（`src/engine/index.js`）已提交。

## 目标

在现有原型界面上做四项改动，并接入真实引擎、删除假数据层：

1. 构建模式画出全部 65536 个格点，配剖切框看内部。
2. 时间步模式镜头飞进选中格点周围的 5×5×5 局部块，块内每个格点的 7 个分量画成方块，每个子步有逐格点动画。
3. 检查器显示子步前 / 后 / Δ。
4. 浓度改为全三维体渲染，可选叠一张切片。

## 允许改动的文件

- 修改：`lbm3d-cl/index.html`、`style.css`、`src/app.js`、`src/ui/*.js`
- 新建：`src/ui/` 下新模块（如 `block-view.js`、`volume-view.js`、`clip-box.js`、`url-state.js`）
- 删除：`src/engine/mock-engine.js`
- 修改：`index.html` 的 importmap 改为指向 `vendor/`（任务 001 已放入 three.js r170）

**不改**：`src/engine/` 下除删除 mock 以外的任何文件、`test/`、`reference/`、`docs/`、`.claude/`。引擎接口不够用时，在汇报里写明需要什么，不要自己改引擎。

## 一、引擎接入

- `src/app.js` 及 `src/ui/*` 的 import 全部改为 `./engine/index.js`（或相应相对路径），删除 `mock-engine.js`。
- 求解器参数用引擎默认值；URL 参数 `dt=` 可覆盖 Δt（见第六节）。页脚 Δt、η 显示实际生效值（`solver.params`）。

## 二、构建模式：全格点 + 剖切框

**格点**：所有格点都画成点（`THREE.Points`，`sizeAttenuation`，尺寸 0.22，颜色 `#8e9a96`，不透明度 0.55）。某格点被重构写成离聚物、碳或铂后，点隐藏，改画实心方块（现有 `InstancedMesh`，边长 0.94，相位色）。孔隙格点始终是点。缓冲层与墙沿用现有半透明板。去掉原型里"只画外表面"的逻辑。

**剖切框**：

- 用 three.js 局部裁剪平面（`renderer.localClippingEnabled = true`），6 个平面同时作用于点、方块、缓冲层板。
- 格点画布左上角放一个浮动小面板（白底 0.92 不透明、圆角 6px、字号 11px、宽约 200px）：标题"剖切"加一个开关；下面 x、y、z 三行，每行一个双滑块（最小值、最大值，步长 1）和数字显示。
- 默认开启，范围 x [0, L−1]、y [H/2, H−1]、z [0, W−1]，即切掉靠近镜头的一半，露出 y = H/2 截面。
- 裁剪框边界画金色虚线框（`#c99a2e`，dashSize 0.6，gapSize 0.4）。
- 拾取：在裁剪范围内对方块和点做射线检测（点的阈值 0.4），取最近的格点。选中格点不再带动剖切面移动。

**τ 阶段**：孔隙点改按 τ 着色（沿用 `tauColor`），尺寸 0.4；图例下方加一条 τ 色标（0.5 → 1.9），只在这一阶段显示。

## 三、时间步模式：5×5×5 局部块

### 布局与镜头

- 局部块以选中格点为中心，`x0 = clamp(selX − 2, 0, L − 5)`，y、z 以选中点为中心并周期取模（块可跨 y/z 边界）。
- 进入时间步模式或改选格点时，镜头用 600 ms（easeInOutCubic）飞到局部块：目标点为块中心，方向与全局默认视角相同 `(0.32, −1, 0.5)`，距离使块占画布高度约 70%。
- 全域结构保留作背景：方块不透明度降到 0.08，点隐藏，剖切框隐藏。
- 格点画布右上角在"重置视角"旁加按钮"全局 / 局部"切换：全局时回到全域视角（背景恢复正常不透明度，局部块仍显示）。

### 块内元素

- 流体格点（孔隙、离聚物、缓冲层）：画一个淡线框（边长 0.9，`#c9d1ce`，不透明度 0.5），内部画 7 个分量方块。
- 分量方块 k：位置为格点中心 + 0.3·e_k（k=0 在中心）。边长 `0.10 + 0.22·√min(1.5, f_k / (WEIGHT[k]·c_in))`，不透明度 `0.35 + 0.65·√min(1, f_k / (WEIGHT[k]·c_in))`，颜色 `#1f7a72`。
- 固相格点（碳、铂、墙）：实心方块边长 0.9，相位色，不透明度 0.22（铂 0.35），`depthWrite: false`。
- 选中格点：金色线框（`#c99a2e`，边长 1.06）。
- 块内点击任意格点即选中它，块和镜头随之移动。

### 子步动画

数据：每个子步执行前用 `solver.block(x0−1, y0−1, z0−1, 7)` 取一次 7³ 的分量（多一圈用来知道从块外流进来的值），执行后再取一次。只渲染中间 5³。

时长：每个子步 900 ms ÷ 速度，缓动 easeInOutQuad。自动播放时子步之间停 300 ms。进度 p ∈ [0, 1]。

| 子步 | 动画 |
|---|---|
| 迁移 | 每个格点 A 的分量 k≠0 从 A+0.3e_k 平移到 B+0.3e_k（B = A+e_k），尺寸从子步前的值渐变到 B 处子步后的值。B 为固相：方块只走到 A+0.5e_k 的面上停住，p≥0.6 时变成反弹色。B 为离聚物而 A 为孔隙（或反之）：方块变成共轭界面色。移出块的方块在最后 30% 淡出；从块外流入的方块在前 30% 从块面淡入（值取 7³ 外圈）。选中格点流出的分量画成 1.6 倍、迁移色；流入的分量画成 1.6 倍、金色。 |
| 反弹 | 上一步停在面上的反弹色方块，从 A+0.5e_k 移回 A+0.3e_{opp(k)}，尺寸渐变到子步后的值。其余方块不动。 |
| 入口 | 块内 x=1 的格点：f₁ 方块外加金色线框，不透明度按 sin(πp) 闪一次，尺寸渐变到子步后的值。块内没有 x=1 时：全局背景里在 x=1 处画一张迁移色半透明平面，不透明度按 0.35·sin(πp) 脉冲，说明文字补一句"入口层不在当前局部块内"。 |
| 宏观量 | 每个流体格点：p ∈ [0, 0.6] 时 7 个方块向中心收拢、缩小到 0；同时中心出现一个球，半径 `0.12 + 0.25·∛(c/c_in)`，颜色 viridis(c/c_in)。p ∈ [0.6, 1] 时方块回到原位（宏观量不改变分量）。球保留到碰撞子步开始，在碰撞前 30% 淡出。 |
| 反应 | src > 0 的离聚物格点：中心球半径渐变到按 c−src 计算的值；在朝向每个铂邻居的面上画一个反弹色圆片（半径 0.3），不透明度 sin(πp)。src = 0 的格点不动。 |
| 碰撞 | 所有方块尺寸从子步前渐变到子步后的值；每个方块外画一个子步前尺寸的金色线框，不透明度从 0.8 线性降到 0；格点线框按 sin²(πp) 闪一次共轭界面色，强度正比于该格点 Σ|Δf_k|（以块内最大值归一化）。 |

连续求解时不播放子步动画，块内方块按当前值每 100 ms 刷新一次。

### 子步说明文字（定稿文案）

- 迁移："每个格点的 6 个运动分量沿各自方向移到相邻格点（式 2-32 左侧）。朝向碳、铂的分量停在界面上，下一子步反弹；孔隙与离聚物之间按共轭界面公式交换（式 2-44、2-45）。"
- 反弹："停在固相界面上的分量原路返回，变成反方向的分量，氧气不进入碳和铂。"
- 入口："x = 1 的缓冲层格点按恒浓度边界重设 f₁ = c_in/4 − f₂（式 2-40）。"
- 宏观量："每个格点 7 个分量求和得到氧气浓度 c = Σf_i（式 2-38）。"
- 反应："与铂相邻的离聚物格点按 Butler-Volmer 方程消耗氧气（式 2-23），过电势取定值 η。"
- 碰撞："在矩空间按松弛矩阵 S 向平衡态松弛（式 2-32 右侧、2-35、2-36），并扣除反应消耗。"

## 四、检查器

## 五、浓度面板：体渲染

- 删除现有两张正交切片。
- 新建体渲染：`BoxGeometry(L, H, W)`，`side: BackSide`，自定义 `ShaderMaterial` 光线步进。
  - 纹理：浓度 `Data3DTexture`（R8，值 = round(255·min(1, c/c_in))，线性过滤），相位 `Data3DTexture`（R8，最近邻过滤），viridis 一维查找表（256×1）。
  - 步长 0.5 格，最多 256 步，前向合成，累计不透明度 ≥ 0.97 提前结束。
  - 流体样本：颜色 viridis(t)，每单位长度不透明度 `0.04 + 0.5·t^1.5`（按步长换算）。
  - 固相样本（相位 ≥ 2）："显示固相"开时颜色 `#9aa5a1`、每单位长度不透明度 0.06；关时完全透明。
  - 求解时浓度纹理最多每 100 ms 更新一次。
- 面板标题栏右侧（"连续求解"按钮左边）加：开关"显示固相"（默认开）、开关"切片"（默认关）、切片轴选择 x / y / z（默认 y）、切片位置滑块。
- 切片开启时，在该位置画一张不透明平面，着色规则同原型切片（流体 viridis，固相相位色），体渲染照常。
- 选中格点金色线框、入口/出口标签、色标条、右侧剖面曲线和诊断数据保留。

## 六、固定状态 URL（验收用）

页面读取以下 URL 参数，按顺序把状态推进到位后冻结，用于可重复截图：

| 参数 | 含义 |
|---|---|
| `seed` | 随机种子，默认 42 |
| `dt` | 覆盖 Δt |
| `mode` | `build` 或 `step` |
| `stage`、`p` | 构建阶段 0~6 与该阶段进度 0~1 |
| `t` | 先跑 t 个完整时间步 |
| `sub` | 再依次执行子步直到下标 `sub`（含） |
| `ap` | 冻结子步动画在进度 ap（0~1），不再自动推进 |
| `sel` | 选中格点 `x,y,z` |
| `cam` | `global` 或 `block` |
| `clip` | `0` 或 `1`，或 `x0-x1,y0-y1,z0-z1` |
| `slice` | 如 `y16`，开启切片 |
