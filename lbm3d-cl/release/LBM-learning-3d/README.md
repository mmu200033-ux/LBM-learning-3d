# LBM 三维学习演示发布包

## 运行

双击 `LBM-learning-3d.exe`。启动器会在本机随机端口启动静态服务器，并自动打开浏览器。关闭启动器窗口即可停止服务。

也可以将本目录放在任意位置后运行，不需要安装 Node.js。

## 文件

- `LBM-learning-3d.exe`：Windows 启动器
- `index.html`、`style.css`、`src/`、`vendor/`：网页程序
- `cache/`：默认 seed=42 的 400 帧真实 LBM 浓度缓存

## 说明

默认浓度回放使用预计算缓存，可立即拖动完整 400 帧时间轴。更改 seed 后，如果没有对应缓存，页面会回退到浏览器实时计算。
