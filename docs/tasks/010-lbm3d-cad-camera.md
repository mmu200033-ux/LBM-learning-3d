# 任务 010：CAD 式自由视角 + 时间步模式去掉缓冲层和墙

背景：`docs/design/lbm3d-cl.md`。基线是当前工作区（任务 007、008、009 的改动，可能尚未提交）。

## 问题

1. 任务 008 把 OrbitControls 的 target 固定在结构中心，这不是用户要的。用户要 CAD / 建模软件那种**任意中心、随便缩放**的视角。
2. 时间步模式下两端的墙板（大灰板）仍然显示。用户要求时间步模式下缓冲层和墙都不显示。

## 要做的

### 一、自由视角（三维格点画布，构建和时间步两种模式都适用）

- **左键拖动**：绕当前 target 旋转。
- **右键拖动、或 Shift + 左键拖动**：平移，target 随之平移（屏幕空间平移，`controls.screenSpacePanning = true`）。
- **滚轮**：朝鼠标所指位置缩放（`controls.zoomToCursor = true`，three.js r170 的 OrbitControls 支持）。缩放范围放宽：`minDistance = 2`，`maxDistance = 结构对角线长度 × 4`。
- **不自动改视角**：点选格点、局部块移动、切换子步、切换模式时，都不改 camera 和 target。删除任务 005 里"局部块移动时 600 ms 飞到块中心"的逻辑，也删除任务 008 里"target 固定为结构中心"的逻辑。
- **重置视角**按钮：回到默认视角（构建模式看整个结构；时间步模式看局部块，块占画布高度约 45%）。只有这个按钮会改视角。
- 首次进入时间步模式时，用一次"重置视角"的效果，之后不再自动改。
- 右键菜单：在画布上禁用浏览器默认右键菜单（`contextmenu` 事件 `preventDefault`），否则右键平移会弹菜单。
- 点选判定：拖动距离 > 4 px 视为拖动、不触发选点（现有逻辑保留），右键不触发选点。

### 二、时间步模式去掉缓冲层和墙

- 时间步模式下，缓冲层网格（任务 007 已隐藏）和墙网格都设 `visible = false`。
- 构建模式下保持现状（缓冲层、墙都显示）。
- 只改显示，不改结构数据和求解器。

## 允许改动的文件

- 修改：`lbm3d-cl/src/ui/lattice-view.js`、`lbm3d-cl/src/ui/stage.js`、`lbm3d-cl/src/app.js`（如果视角切换逻辑在这里）

**不改**：`src/engine/`、`src/ui/block-view.js`（任务 009 刚改过）、`index.html`、`style.css`、`test/`、`docs/`。

## 验收

我会在浏览器里打开 `http://localhost:8771/?mode=step&t=300&sub=0` 亲手操作检查：

1. 右键拖动能平移，滚轮朝鼠标位置缩放，左键拖动绕新中心旋转。
2. 点选另一个格点后，视角不跳。
3. 「重置视角」回到局部块默认视角。
4. 时间步模式下看不到缓冲层和墙；切回构建模式，缓冲层和墙重新出现。
5. `node --check` 改过的文件通过；`node --test lbm3d-cl/test` 5/6 通过（预算测试失败是已知问题）。
